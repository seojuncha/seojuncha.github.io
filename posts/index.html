Blog

Exploring low-level programming, media processing, Qt development, and Common Lisp.

Welcome to my blog, where I dive deep into low-level programming, media processing, Qt development, and Common Lisp. From assembly-level insights to GUI applications and functional programming, this blog is a collection of my explorations, experiments, and discoveries.

Each post is designed to share practical knowledge, whether it’s understanding how hardware works, optimizing media pipelines, building efficient UIs, or leveraging Lisp for advanced metaprogramming.

If you’re passionate about deep technical topics and love exploring how things work under the hood, you’re in the right place!

Key Categories:

  • Low-Level Programming – Assembly, Verilog, system programming.
  • Media – Video codecs, streaming, and FFmpeg.
  • Qt/QML – High-performance GUI development.
  • Common Lisp – Functional and metaprogramming.

Low-Level Programming

Low-level programming is the foundation of computing. This category explores assembly, C, and hardware-related topics, focusing on how software interacts directly with hardware. You’ll find content on ARM Assembly, Verilog, system programming, and embedded systems, bridging the gap between software and hardware. Key Topics: ARM Assembly, Verilog, Computer Architecture, System Programming, Embedded Development.

Media

Media processing is more than just playing videos—it’s about codecs, streaming, and efficient data handling. Qt is a powerful cross-platform GUI framework, and QML offers a declarative UI language for smooth and responsive applications. In this category, I share insights on Qt development, GUI architecture, performance optimization, and real-world application building. Key Topics: Qt Widgets, QML, Cross-Platform Development, GUI Performance Optimization.

Common Lisp

Common Lisp is a dynamic, expressive, and powerful programming language with a deep history in AI, symbolic computation, and metaprogramming. This category explores Lisp fundamentals, macro programming, compiler construction, and modern applications of Lisp. Key Topics: Lisp Macros, Compiler Construction, Functional Programming.
