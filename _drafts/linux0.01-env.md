리눅스 커널에 대한 관심이 생기면서 Dinus Torvalds는 어떻게 최초 버전의 리눅스를 개발했는지 궁금했다.
현대의 리눅스 커널은 많은 디바이스. 드라이버와 다양한 아키텍쳐 지원으로 인한 코드 크기가 늘어났기 때문에 가장 간단한 형태의 초기 커널을 선택했다.
1991년에 개발된 커널인 만큼 2026년 현재의 컴파일러와 라이브러리로는 쉽게 빌드할 수 없었다.
다행히도 mariuz github에서 빌드에 성공하고 에뮬레이터 동작까지 확인한 버전을 참고할 수 있었다.
직접 빌드는 건너뛰고 커널 내부 동작의 분석에 집중했다.
전체 소스코드와 시스템 이미지 파일 등은 [Gitub 저장소](https://github.com/seojuncha/1inux-0.01-revival) 에서 확인할수있다.

## 왜 Bochs 애뮬레이터가 필요한가?
단순히 코드만 봐서는 여러면에서 분석이 어렵고 임의의 동작이 정확하게 수행되었는지 확인하기가 어렵다.
코드를 읽는 것은 단지 논리적/추상적인 추적일 뿐이라고 생각한다.
실제로 동작하는게 중요하다.
그래서 직접 빌드하는 과정은 건너뛰고 mariuz 가 현대 컴파일러 및 툴체인 환경에 맞게 수정하여 에뮬레이터를 사용할 수 있도록 수정해준 코드를 활용했다.
sochs 에뮬레이터를 사용해서 CPU RESET 시점부터 BIOS 실행, 커널 내부 진입까지 추적할 수 있다.

### OEMU 를 사용하지 않는 이유
OEMU 8.2 버전을 사용해서 테스트해봤을 때, 리눅스 실행은 가능하다.
하지만 문제는 GDB를 연결해서 정상적으로 디버깅할 수가 없었다.

## 리눅스 커널 준비
지금까지 Bochs 애뮬레이터를 준비했고 이제_실제 리눅스 0.01 커널을 준비해보자.
리눅스 0.01버전은 크게 512바이트의 부트코드와 시스템 (커널) 코드를 하나의 바이너리에 병합하여 생성한다.
최종 산출물은 RAW 바이너리 형식의 `Image` 파일이다.

### 부트코드 및 커널 빌드 수정된 리눅스 0.01. 버전의 빌드는 아주, 간단하다.
소스 코드가 있는 linux 디렉토리로 이동한 후에 make 를 실행한다.
> 앞서 설명한 [개인 저장소](httpa://github.com/seojuncha/linux-0.01-revival)를 내려받았음을가정한다.
> git clone https://github.com/seojuncha/linux-0.01-revival
> 하지만, 추후 업데이트 되면서 상세한 디렉토리 위치는 변경될 수 있으므로 참고하자.

### Bochs 설정 파일 및 hd_oldlinux.img 압죽 해제
이제 마지막 단계로 Bochs 설정파일을 확인하고 애뮬레이터의 하드디스크에 로딩할 이미지 파일(hd_oldlinux.1mg)을 준비한다.
emulation 디렉토리는 6ochs 애뮬레이터를 실행하기 위한 설정파일과 디스크 이미지가 있다.
```bash
cd emulation
```

먼저 Bochs 하드디스크에 로딩될 디스크. 이미지를 준비한다.
```bash
unzip hd_oldlinux.img.zip
```
