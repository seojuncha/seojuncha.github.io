Low-Level Programming

컴퓨터의 근본을 이해하는 프로그래밍 – 어셈블리, C, 그리고 하드웨어와의 상호작용.

로우레벨 프로그래밍은 컴퓨팅의 기초입니다. 이 카테고리는 어셈블리, C, 하드웨어 관련 프로그래밍을 다루며, 소프트웨어가 하드웨어와 직접 상호작용하는 방식을 탐구합니다.

ARM 어셈블리, Verilog, 시스템 프로그래밍, 임베디드 개발 등의 주제를 다루며, 소프트웨어와 하드웨어의 경계를 깊이 이해하는 것을 목표로 합니다.

주요 주제: ARM 어셈블리, Verilog, 컴퓨터 아키텍처, 시스템 프로그래밍, 임베디드 개발

테스트 벤치와 Verilog 개발 환경 설정: Icarus Verilog와 cocotb

예제로 알아보는 컴퓨터 연산의 Overflow
