블로그

로우레벨 프로그래밍, 미디어 처리, Qt 개발, 그리고 Common Lisp을 연구합니다.

이 블로그에서는 로우레벨 프로그래밍, 미디어 처리, Qt 개발, 그리고 Common Lisp을 깊이 연구합니다. 어셈블리 언어에서 GUI 개발, 함수형 프로그래밍까지, 다양한 주제에 대한 연구와 실험을 기록하는 공간입니다.

각 게시물은 하드웨어 작동 방식 이해, 미디어 파이프라인 최적화, 효율적인 UI 구축, 고급 메타프로그래밍을 위한 Lisp 활용 등 실용적인 지식 공유를 위해 작성되었습니다.

기술적인 깊이를 추구하는 개발자라면, 이 블로그에서 흥미로운 내용을 많이 찾을 수 있을 것입니다!

주요 카테고리:

  • Low-Level Programming – 어셈블리, Verilog, 시스템 프로그래밍
  • Media – 비디오 코덱, 스트리밍, FFmpeg
  • Qt/QML – 고성능 GUI 개발
  • Common Lisp – 함수형 및 메타프로그래밍

Low-Level Programming

로우레벨 프로그래밍은 컴퓨팅의 기초입니다. 이 카테고리는 어셈블리, C, 하드웨어 관련 프로그래밍을 다루며, 소프트웨어가 하드웨어와 직접 상호작용하는 방식을 탐구합니다. ARM 어셈블리, Verilog, 시스템 프로그래밍, 임베디드 개발 등의 주제를 다루며, 소프트웨어와 하드웨어의 경계를 깊이 이해하는 것을 목표로 합니다. 주요 주제: ARM 어셈블리, Verilog, 컴퓨터 아키텍처, 시스템 프로그래밍, 임베디드 개발

Media

미디어 프로세싱은 단순히 영상을 재생하는 것이 아니라, 코덱, 스트리밍, 효율적인 데이터 처리를 포함하는 복잡한 기술입니다. 이 카테고리에서는 비디오 압축, 실시간 스트리밍, FFmpeg, 미디어 파일 분석을 다루며, 저수준 프로그래밍 관점에서 미디어 처리 기술을 깊이 파고듭니다. 주요 주제: FFmpeg, 비디오 코덱, 스트리밍 기술, 로우레벨 미디어 프로세싱

Qt/QML

Qt는 강력한 크로스 플랫폼 GUI 프레임워크이며, QML은 선언형 UI 언어로 부드럽고 반응성이 뛰어난 애플리케이션을 개발할 수 있도록 해줍니다. 이 카테고리에서는 Qt 개발, GUI 아키텍처, 성능 최적화, 실전 애플리케이션 제작과 관련된 다양한 내용을 다룹니다. 주요 주제: Qt 위젯, QML, 크로스 플랫폼 개발, GUI 성능 최적화

Common Lisp

Common Lisp은 동적이고 표현력이 뛰어난 강력한 프로그래밍 언어로, 인공지능, 심볼릭 연산, 메타프로그래밍에서 깊이 활용됩니다. 이 카테고리에서는 Lisp 기본 개념, 매크로 프로그래밍, 컴파일러 개발, 현대적인 Lisp 활용법을 다루며, Lisp의 진정한 가치를 탐구합니다. 주요 주제: Lisp 매크로, 컴파일러 개발, 함수형 프로그래밍
