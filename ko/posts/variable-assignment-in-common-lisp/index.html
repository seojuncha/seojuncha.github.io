변수의 사용은 프로그램을 개발할 때 가장 기초가 되는 내용 중 하나입니다. Common Lisp은 다른 언어와는 변수의 사용방식에서 다소 상이한 방식을 제공하고 있습니다. 이번 포스팅에서는 Common Lisp에서 제공하는 다양한 변수 할당 방식을 실제 예제와 함께 살펴보고 각각의 유의점을 살펴보겠습니다.

전역 변수의 생성: defvar, defparameter#

가장 먼저 살펴볼 변수 할당 방법은 defvar과 defparameter를 사용한 전역 변수(Global Variable) 할당입니다. Lisp프로그램을 작성할 때 가장 쉽게 변수를 생성할 수 있는 방법입니다. 각각은 모두 전역범위의 변수를 생성합니다.

(defvar *a*)    ; 값 할당 없이 변수 a 선언
(defvar *b* (list 1 2 3))  ; 변수 b 에 리스트 (1 2 3) 할당
(defvar *my-array* (make-array 2))  ; 변수 my-array에 2차원 배열 생성

defvar와 동일하게 defparameter를 사용할 수 있습니다.

(defparameter *a*)  ; 오류 발생
(defparameter *b* '(1 2 3))
(defparameter *c* nil)

다만 defparameter는 defvar와 다르게 변수 생성시 초기화 값이 필요합니다.

예제 코드에서 볼 수 있듯이 Lisp에서 전역변수는 변수명 앞뒤에 *로 감싸서 작성합니다.

Lisp이 다른 언어와 구분되는 점 중 하나로써, 일반적인 C언어 기반의 프로그래밍 언어의 경우 코드의 문법적인 위치에 따라서 전역/지역 변수가 결정되지만 Lisp은 특정 키워드(예: defvar, let)를 사용해서 명시적으로 변수의 스코프를 결정합니다.

지역 변수 생성: let#

명시적으로 지역 변수(Local Variable) 또한 생성할 수 있습니다. 지역 변수는 다른 프로그래밍 언어에서와 같이, 특정 범위내에서만 유효한 변수입니다. Lisp에서는 let을 사용해서 특정 변수를 지역 범위를 가지도록 생성할 수 있습니다.

(let ((a 1)   ; 지역변수 a 를 1로 초기화
       c)     ; 지역변수 c 를 nil로 초기화
  (format t "~d~%" a))
(format t "~d~%" a)  ; 오류 발생, 변수 a는 let범위 내에서만 유효함

함수에서 let 사용하기#

Lisp에서 함수 호출 시 전달하는 파라미터 역시 지역범위의 변수로 생성됩니다.

(defun foo (number)   ; foo 함수 파라미터 변수 number, 지역 범위
  (incf number)
  (format t "number: ~a~%" number))

(foo 20)  ; 함수 인자 20과 함께 foo함수 호출
(format t "number: ~a~%" number)   ; 오류 발생

다른 프로그래밍 언어와 마찬가지로, 함수 호출시 전달되는 인자는 함수 내부에서만 사용가능한 파라미터 변수로 할당됩니다. 따라서, 함수 파라미터는 함수가 종료되면 함수 외부에서는 사용할 수가 없죠. 또한 내부에서 새로운 변수를 사용해야 할 때는 어떻게 해야할까요?: 함수 내부에서 let을 사용하면 됩니다.

(defun foo (number)  ; 함수 파라미터 number, 지역 범위
  (let ((plus-one 0))   ; 지역변수 plus-one 생성
    (setq plus-one (+ number 1))  ; plus-one에 number+1 할당
    (format t "plus: ~d~%" plus-one)))

(foo 20)  ; foo 함수 호출

위와 같은 코드를 작성하면 함수 foo내부에서 새롭게 생성된 지역변수 plus-one을 활용할 수 있습니다.

기존 변수와 let의 관계#

let은 새로운 지역 변수를 생성하는 것이기 때문에 동일한 이름을 가진 다른 변수의 값을 가릴 수 있습니다.

(defvar a 10)   ; a = 10 바인딩 생성
(let ((a 5))    ; 새로운 a 지역변수 생성, a = 5 바인딩 생성
  (format t "~d~%" a))
(format t "~d~%" a)  ; let의 범위를 벗어나므로 10을 출력

(defvar a 10)으로 인해 변수 a에 숫자 객체 10으로 새로운 변수가 생성되었습니다. 이후에 let문을 사용하게 되면, 동일한 심볼(변수 이름)이더라도 완전히 새로운 변수가 생성되기 때문에, let문 안에서 사용하는 변수 a는 전역변수 a가 아닌 지역변수 a입니다.

전역 변수의 변수명에 *를 사용하는 이유이기도 합니다.

변수값 변경: setq#

앞서 살펴본 defvar, defparameter, let은 새로운 변수를 생성하는 키워드 입니다. (좀 더 정확하게는 새로운 변수 바인딩을 생성하는 것 입니다.) 이렇게 새로 생성된 변수는 setq를 사용해 변수의 값을 변경할 수 있습니다.

(defparameter *a* nil)
(setq *a* 'a)

setq는 let혹은 defvar, defparameter와 함께 사용할 것#

setq는 새로운 변수를 생성하는 것이 아니라 기존에 생성된 변수의 값을 수정하는 용도입니다. 그렇기 때문에 단독 사용은 지양하고 let이나 defvar 혹은 defparameter와 같은 변수 생성 구문과 함께 사용하는 것이 좋습니다.

(let ((num 10)  ; 초기값이 있는 경우
      (n nil))  ; 초기값이 없는 경우
  (format t "~d~%" num)    ; 10 출력
  (setq num (+ num 2))     ; num = 12
  (setq n (+ num 2))       ; n = 14
  (format t "~d ~d~%" num n))  ; 12 14 출력

setq를 단독으로 사용하면?

변수 생성 과정 없이 사용할 경우, setq는 해당 변수를 글로벌 변수로 할당합니다. 이것은 명시적으로 변수의 범위를 설정하는 Lisp문법에 위배되기도 하고, 프로그래머가 실수하기 쉽습니다. 그렇기 때문에, SBCL환경의 경우 경고 메세지를 출력합니다.

상수의 생성: defconstant#

Lisp은 다른 프로그래밍 언어와 같이 상수(Constant) 변수 역시 생성할 수 있습니다.

(defconstant +name+ "seojun")   ; 문자열 상수 선언
(format t "~a~%" +name+)

(setq +name+ "who")  ; 오류 발생, 상수는 값 변경 불가능

상수는 변수 이름의 앞뒤에 +기호로 감싸서 작성합니다.

객체와 심볼의 바인딩#

Lisp에서 변수는 기본적으로 바인딩(Binding)의 개념을 따릅니다. 즉, 값 자체를 직접 저장하는게 아니라 객체에 대한 참조를 저장합니다. 참고로, Lisp에서는 숫자와 문자를 포함한 모든 요소를 객체 혹은 심볼로 다룹니다.

객채와 심볼, s-expression과 같은 내용은 다른 포스팅에서 다룰 예정입니다.

예를 들어, (defvar a 1) 를 사용하여 전역변수를 생성하는 경우 아래와 같은 변수-값 바인딩을 생성합니다.

 +---+      +---+
 | 1 | <--- | a |
 +---+      +---+
  객체     변수(심볼)

현대 프로그래밍 언어와의 차이점#

지금까지 살펴본 바와 같이 Lisp은 Python이나 C와 같은 현대 언어에 비해 더욱 명확한 변수 할당 방식과 스코프를 지정할 수 있도록 하고 있습니다. Python과 C를 비롯한 대부분 현대의 프로그래밍 언어는 변수의 문맥적 위치에 따라서 자동으로 지역 범위인지 전역 범위인지 결정합니다.

int a = 10;     // 전역 변수 a
void foo () {
  int a = 20;   // 지역 변수 a
  printf("%d", a);  // 20 출력
}
printf("%d", a);  //10 출력

a = 10    # 전역 변수 a
def foo ():
  a = 20
print(a)  # 20 출력

하지만, Lisp은 연산자와 매크로를 사용하여 변수의 할당방식을 명시적으로 지정하도록 하여 컴파일러 최적화 및 효율적인 디버깅 방식을 제공할 뿐아니라 다른 언어에서 제공하지 못하는 유연성을 확보할 수 있습니다.
